# WN Download Manager (Windows Edition)

**WN Download Manager** is a powerful, open-source desktop application that I developed as the Windows version of **MC Download Manager**, the download manager [Mesut Çevik](https://github.com/) built for macOS. Unlike the original project, it adds the ability to download videos together with their subtitles. It brings the original project's multi-segment, high-speed download experience to the Windows ecosystem using modern Python and **ttkbootstrap**.

It offers the advanced features of professional tools such as Internet Download Manager (IDM) and MC Download Manager with a Turkish interface and a modern dark theme.

> This project is inspired by MC Download Manager, developed by Mesut Çevik for macOS, and has been redeveloped for Windows users. Additional features have been added for ease of use.

---

## 🚀 Key Features

- **Multi-Segment Parallel Downloading**:
  - Splits files into 1 to 32 segments using HTTP Range requests for maximum bandwidth usage.
  - Dynamic merging of segments and file integrity checks (Content-Length).
- **Pause & Resume**:
  - Pause downloads at any time and resume from the exact byte where they left off.
  - Download state is automatically preserved in SQLite in case of power outages or unexpected application shutdowns.
- **Video & Media Downloader (yt-dlp Integration)**:
  - Download video and audio directly from YouTube, Twitter, Instagram, TikTok, Vimeo, and hundreds of other sites.
  - Format options: 4K (2160p), 1080p, 720p, 480p, and Audio Only (MP3).
  - Automatic audio and video merging with FFmpeg.
- **Subtitle Downloading (2 Types)**:
  - **Manual (Uploaded) Subtitles**: Downloads official subtitles uploaded by the video owner.
  - **Auto-Generated Subtitles**: Downloads subtitles automatically generated by the platform.
- **Automatic Clipboard Monitoring**:
  - Automatically analyzes copied links and opens a quick download window when a downloadable file or video is detected.
- **Modern and Sleek Interface (ttkbootstrap - Darkly Theme)**:
  - Filter by category: *All, Documents, Images, Music, Video, Archives, Programs, Other*.
  - Live speed, estimated time remaining (ETA), and percentage indicators for each download.
  - Segment detail window for visually inspecting the status of each segment.
- **System Tray Integration**:
  - Runs quietly in the background with quick access via a right-click menu.
- **Desktop Notifications**:
  - Windows desktop notification when a download completes.
- **Custom Headers & Speed Limit Support**:
  - Download with a custom User-Agent, Referer, and cookies.
  - Set a speed limit in KB/s to balance network usage.

## 🛠 Installation

### 1. Requirements
- Python 3.9 or newer (Windows 10 / 11)
- [Optional] `ffmpeg` is recommended on your system for merging video and audio.

### 2. Installing Dependencies
**First, make sure Python is installed on your computer.** To check, run the following command in PowerShell or CMD:

```powershell
python --version
```

If you see a version number (e.g. `Python 3.11.5`), Python is installed. If you get an error, download and install it from [python.org](https://www.python.org/downloads/) (don't forget to check **"Add Python to PATH"** during installation).

Once you have confirmed that Python is installed, run the following command in the project directory using the command prompt (PowerShell or CMD):

```powershell
pip install -r requirements.txt
```

## 💻 Usage

To start the application, first navigate to the project folder in the command prompt (PowerShell or CMD), then run the application:

```powershell
cd C:\Path\To\wn-download-manager-win
python main.py
```

> Replace `C:\Path\To\wn-download-manager-win` with the path of the folder where you saved the project on your computer. For example, if the project is on your Desktop: `cd C:\Users\YourUsername\Desktop\wn-download-manager-win`

### Keyboard Shortcuts:
- **Ctrl + N**: Opens the Add New Download window.
- **Delete**: Removes the selected download.
- **F5**: Refreshes the download list.
- **Double Click**: Shows the segment details and progress of the selected download.
- **Right Click**: Opens a menu to pause, resume, open in folder, or delete the file.

    └── icon.py              # Application icon and generator functions

## ⚙️ Configuration and Data Storage

Application settings and download history are stored in the `.mc_download_manager` folder in the user's home directory:
- **Configuration File**: `~/.mc_download_manager/config.json`
- **Database**: `~/.mc_download_manager/downloads.db`
- **Application Log**: `~/.mc_download_manager/mcdm.log`
